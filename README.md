# MoGe-2 WebGPU Spatial Scene

A browser-only demo that turns one photograph into a calibrated textured 2.5D scene. The photo is processed locally; it is never uploaded.

> [!NOTE]
> This project and its documentation were generated by AI, then validated through automated tests, strict TypeScript checking, and a production build. Real macOS AMD WebGPU hardware validation is still required as described below.

```text
Image → MoGe-2 ONNX → ORT WebGPU → MoGe postprocess
      → metric point map → depth-aware mesh → Three.js WebGL2
      → calibrated Spatial Scene
```

## Requirements

- Current stable Chrome or Edge on macOS
- Hardware-accelerated WebGPU (the acceptance target is an AMD Mac)
- HTTPS in production; `http://localhost` is valid for development
- Node.js 24, or Nix with flakes enabled

Safari and Firefox are not MVP targets.

## Run

With Nix:

```sh
nix develop
npm install
npm run model:download
npm run dev
```

Without Nix, use Node 24 and run the same npm commands. The official FP32 `Ruicheng/moge-2-vits-normal-onnx` asset is downloaded to `public/models/moge-2-vits-normal.onnx`; the large binary is ignored by Git.

Checks and production build:

```sh
npm test
npm run typecheck
npm run build
```

`dist/` is static-hostable. If `VITE_MOGE_MODEL_URL` is set at build time, it replaces the default `/models/moge-2-vits-normal.onnx` URL. Configure the static host to serve the ONNX file and WebAssembly with their normal binary MIME types and effective caching.

## Notes

The implementation follows the official [MoGe ONNX contract](https://github.com/microsoft/MoGe/blob/main/docs/onnx.md) and ports the post-processing in [`moge/model/v2.py`](https://github.com/microsoft/MoGe/blob/main/moge/model/v2.py), because the ONNX graph exposes raw affine geometry rather than final camera-space points.

Available views are Spatial, Original, Depth, Normal, Wireframe, and isolated 3D Debug. Spatial mode uses subtle translation-only pointer/touch and idle motion; free orbit is restricted to 3D Debug.

The core MVP limitation is single-view disocclusion: a photograph contains no surfaces hidden behind foreground objects. Small camera motion and depth-boundary cuts reduce artifacts, but the demo does not reconstruct or inpaint unseen content.
